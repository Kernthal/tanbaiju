# 坦白局

> 今天一人问一个问题，我全部如实回答

一个匿名提问 + 如实回答的社交网站。零依赖、双击即跑。

---

## 快速开始

双击 **`start.bat`**，浏览器自动打开 `http://127.0.0.1:8848`。

关闭那个黑色命令行窗口即停止服务。

> 需要电脑上装有 Node.js。没装的话去 <https://nodejs.org> 下载 LTS 版本，一路下一步即可。

开发时可用 `node tools/restart.js --clean` 重启并清空数据。

## 关于登录：为什么不用微信开放平台扫码登录

你要求参考的两个开源项目（`yi-ge/weixin-login`、`BetterWx-UI`）实现的是
**微信开放平台网站应用扫码登录**。真实链路是：

1. 请求 `open.weixin.qq.com/connect/qrconnect?appid=X&scope=snsapi_login&redirect_uri=Y`
2. 从返回 HTML 正则抠出 `src="/connect/qrcode/{uuid}"`
3. 拼 `open.weixin.qq.com/connect/qrcode/{uuid}` 得到二维码
4. 轮询 `lp.open.weixin.qq.com/connect/l/qrconnect?uuid=X&last=Y`
5. `wx_errcode=405` 即成功，拿到 `code` 再换 access_token 与用户信息

**这条路在没有微信资质的情况下走不通**：

- 微信开放平台要求**企业/组织主体**，个人无法申请
- 审核需**认证费用 300 元/年**
- 必须**域名备案**并配置「授权回调域」
- `access_token` 换取必须持有 **AppSecret** 并在服务端完成

你明确说了不做认证，所以没有绕圈子硬凑，而是**另寻他法**：

**自研扫码登录。** 登录二维码里装的是「本站一次性登录票据」的二维码。
微信扫一扫打开它 → 站点在服务端为对应账号签发会话。

交互形态与微信扫码登录完全一致（扫 → 确认 → 进站），
但身份由本站账号体系承载，**不需要企业认证、不需要 300 元、不需要备案**。
而且二维码是真能扫的（见下文），任何扫码 App 都能用。

三条通道并存，都零资质可用：

| 通道 | 说明 |
| --- | --- |
| 扫码登录 | 二维码内是一次性票据，微信/任意扫码 App 均可 |
| 手机验证码 | 演示环境固定验证码 `8888`，接真实短信只需改 `lib/auth.js` 一行 |
| 账号密码 | 常规注册登录，密码用 scrypt 加盐哈希 |

另有游客模式，未登录也能提问。

## 手绘图标是怎么来的

一开始用的是图标库式的内联 SVG，几何、死板——那不是手绘。
现在是 `tools/make-icons.py` 用 Pillow 以 4 倍超采样绘制真实光栅 PNG：

- 二次/三次贝塞尔构成有机曲线，端点加圆帽
- 中间采样点加入确定性抖动，产生手绘不规则感（同 seed 每次构建一致）
- 黑色 + 透明背景输出，前端用 **CSS mask** 着色，因此图标是真实图片文件，
  同时颜色仍能跟随 `currentColor` 跟随主题变化

favicon 也是同一条管线画出来的对话框气泡，不是拿汉字当图标。

改风格就编辑脚本的曲线控制点，然后：

```bash
python tools/make-icons.py
```

## 真二维码，不是占位图

`lib/qr.js` 是自研 QR 编码器：字节模式、版本 1–10、四档纠错、
自动选掩码、Reed-Solomon 全套（GF(256) 本原多项式 0x11D）。

验证方式是真解码，不是「看起来像」：

- `zxing-cpp` 真实解码回原文，逐字符比对
- **200 个随机长度（1~200 字节）穷举测试全部通过**
- 四档纠错等级各自验证
- 前后端共用同一份实现（`public/vendor/qr.js`）

## 后续扩展社交功能

架构是按「不只有问答」设计的：

- **视图即模块**：把 `window.viewXxx` 定义出来即自动登记为路由，
  不用手动注册（`router.js` 的 `autodiscover()` 扫描）
- **图标可扩充**：`tools/make-icons.py` 的 `ICONS` 字典加一项就多一个图标
- **后端可加路由**：`route(method, path, handler)`，自动支持 `:param` 占位
- **存储已泛化**：`db` 下每个集合都是 `Collection`，新增集合只需在 `store.js` 加一行

想加私信、话题圈、动态评论，都是新增模块而非改造现有代码。

```bash
node test/api-e2e.js        # 63 项：接口 + 权限边界（需服务已启动）
node test/social.js         # 37 项：社交功能（需服务已启动）

node test/browser-guard.js  # 66 项：真实浏览器 + 真实点击（需服务已启动）
```

或直接双击 `test-all.bat`。

**注意**：`browser-guard.js` 是最重要的一项。它用真实 Chrome 加载真实页面，
断言每页都有内容、无运行时异常、图标已注入、骨架屏已清除、控制台无 error，
并**真实点击**验证标签筛选、关注按钮、导航宫格。
早期版本单元测试直接调视图函数、绕过了路由，导致「测试全绿但线上白屏」，
这个测试就是为了防住同类事故。
